# Estado actual de Trigli (2026-10-30)

PWA para registrar alimentación y ejercicio con el objetivo de bajar triglicéridos.
Angular + Ionic + Supabase, deploy en Vercel.

## Pestañas
Resumen, Comidas, Actividad, Fuerza, Lab, Cuenta.

## Funcionalidad
- Login con magic link y recuperación de contraseña
- Comidas: score por comida y diario, kcal por comida, catálogo de alimentos con cortes de carne y gramos opcionales
- Actividad: cardio (meta 150 min/sem), peso y cintura
- Fuerza: doble progresión
- Laboratorio: gráfico de TG
- Resumen semanal con balance calórico (anillo), déficit semanal, proteína, tendencia de peso
- Mi cuenta: perfil, meta, foto, modo claro/oscuro
- Layout desktop con semana como tabla
